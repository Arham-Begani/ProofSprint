# Product direction

ProofSprint is an evidence workshop for a solver comparing plausible answers under time pressure. The main journey is practice or import, compare proposals, challenge checks, inspect evidence and review an unsent draft.

The studio design uses heavy display typography, near-black ink, lime actions and a blue graph-paper proof exhibit. The preview uses actual saved practice records, not fabricated performance. The workspace keeps evidence readable and provides direct section navigation. Mobile has a native answer picker and collapsible source context.

Original CSS/SVG provides entrances, a drawn underline, small transitions, hover feedback and optional pointer tilt. Reduced motion is the default when requested by the system; the user can explicitly enable or pause effects for the visit. No animation dependency or external artwork is included.

Official sites visually studied during the design pass:

- https://hackclub.com/ : welcoming invitation and personality.
- https://posthog.com/ : a coherent product concept and honest demo provenance.
- https://www.raycast.com/ : quick task access and keyboard discoverability.
- https://linear.app/ : strong hierarchy and restrained supporting detail.

These informed principles, not copied layouts, branding, assets or artwork. No independent user research or full WCAG certification is claimed. Responsive, contrast and keyboard checks are described in the validation record.
