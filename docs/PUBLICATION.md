# Public publication scope

This is a curated public source edition of the locally developed ProofSprint v0.4 workbench and its studio redesign. It was prepared after the local redesign and verification were complete. The application was developed with AI assistance; automated fixture checks are not independent human review.

Included: application source, original HTML/CSS/SVG/JavaScript interface, Eve adapter, pinned dependency metadata, environment template with no secret values, synthetic examples, attributed Project Euler problem 1 practice, behavioral tests, and public documentation.

Omitted without deleting the originals: credentials and active environment files; local sessions, source packets and stored responses; build outputs and dependencies; historical logs, screenshots, archives, private planning/conversation links and machine paths; the historical benchmark and its dependent test, because the fixture inputs are not all cleared for republication.

The benchmark scripts were removed from the public package command list. Existing provider-role configuration, evidence gates, model-disabled default and loopback binding were retained. Original frozen local benchmark files were not changed or re-frozen. The public edition does not pretend its test count or manifest is identical to that local research edition.

The loopback address documented in the README is the application's generic default, not a user's LAN address. Original source and documentation were checked for credential patterns, private paths, private network addresses, personal contacts and embedded conversations. Publication commits use the verified GitHub account's no-reply identity and current dates. No pre-existing project Git history or remote existed to carry forward.

No data collection, model inference, registration, puzzle submission, deployment, payment or terms acceptance is performed by publication. Live model performance and competition eligibility remain unverified.
